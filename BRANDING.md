# Event Planner Platform - Branding Kit

## Color Palette

### Primary Colors
- **Primary**: `#8B5CF6` (Violet 500) - Main brand color for CTAs and highlights
- **Primary Light**: `#A78BFA` (Violet 400) - Hover states, lighter accents
- **Primary Dark**: `#7C3AED` (Violet 600) - Active states, darker accents

### Secondary Colors
- **Secondary**: `#EC4899` (Pink 500) - Accent color for special elements
- **Secondary Light**: `#F472B6` (Pink 400)
- **Secondary Dark**: `#DB2777` (Pink 600)

### Neutral Colors
- **Background**: `#FAFAFA` (Gray 50) - Main background
- **Surface**: `#FFFFFF` - Cards, panels
- **Surface Dark**: `#1F2937` (Gray 800) - Dark mode surface
- **Text Primary**: `#111827` (Gray 900)
- **Text Secondary**: `#6B7280` (Gray 500)
- **Border**: `#E5E7EB` (Gray 200)

### Semantic Colors
- **Success**: `#10B981` (Emerald 500)
- **Warning**: `#F59E0B` (Amber 500)
- **Error**: `#EF4444` (Red 500)
- **Info**: `#3B82F6` (Blue 500)

- **Hero Gradient**: `linear-gradient(135deg, #8B5CF6 0%, #EC4899 100%)`

## Illustration Guidelines

### Illustration Sources
- **Primary**: Storyset (https://storyset.com)
- **Secondary**: unDraw (https://undraw.co)

### Illustration Colors
Match illustrations to brand colors:
- Primary: `#8B5CF6`
- Secondary: `#EC4899`
- Neutral: `#6B7280`

### Usage
- **Hero Section**: Large, centered illustration
- **Features**: Small icons or illustrations per feature
- **Empty States**: Centered illustration with message
- **Onboarding**: Step-by-step illustrations
- **Error Pages**: Friendly, reassuring illustrations
